# Professional strategy example

`northstar_storage_market_entry/` is a fully synthetic, deterministic market-entry case used to review the product from a senior strategy analyst's perspective.

- All companies, people, events, figures and URLs are fictional.
- The example is safe to publish and contains no credentials or personal paths.
- Historical/estimated inputs are separated from forecasts, targets and scenarios.
- One material data gap is intentionally left open so the UI must communicate a conditional recommendation and a decision gate.
- No Agent, network connection, Codex login or API key is required.
