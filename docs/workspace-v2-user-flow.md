# Workspace V2 用户流

## 新建研究

项目 → 新建分析（任务、范围、问题、模板与数据计划、确认）→ 运行概览/研究流程 → 人工决策 → Strategy → 研究成果。

## 阻塞处理

BLOCKED_DATA指向数据与质量的数据覆盖；BLOCKED_QUALITY指向Blocking Issues；技术失败留在研究流程。用户不需要从多个按钮猜测下一步。

## 修订

报告完成后进入修订与版本，选择Local Repair、Strategy-only、Fact Verification或Full Re-research；创建前显示STALE阶段、Agent调用、本地重建和额度影响。Human Review不在此页面进行。

## Legacy

V1项目可从项目列表打开并查看最终成果与审计材料，但写入、补搜和修订操作禁用。
